# Reglas del Proyecto (RedVecino & MiVecino)

## 📜 Preservación Estricta de Memoria y Documentación
- **Planes Maestros, PRD, SPEC y HISTORY**: NO se debe sobreescribir ni borrar la información anterior. Se debe entrelazar lo nuevo con lo viejo, añadiendo actualizaciones y manteniendo un historial/trazabilidad completo de lo que se ha planificado y hecho.
- **Formato y Legibilidad**: Al reestructurar documentación (`.md`), se debe mejorar la legibilidad usando GitHub Flavored Markdown, Índices de Navegación Rápida (Table of Contents), Callouts (`> [!NOTE]`, `> [!IMPORTANT]`) y tablas limpias, sin eliminar ningún hito técnico ni detalle del pasado.
